# Differences from Redis 7.4

MiniRedis aims to give the same replies as Redis 7.4 (spec rule 3). These are the intentional differences, each with its reason. A row is added whenever the differential test forces a decision.

| Area                                                           | Redis 7.4                                                                | MiniRedis                                                                                                        |
| -------------------------------------------------------------- | ------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| OBJECT ENCODING                                                | listpack, intset, quicklist, hashtable, skiplist, int, embstr, raw       | the same names minus listpack and intset                                                                         |
| SCAN family on small collections                               | everything in one call                                                   | paged like big ones                                                                                              |
| SCAN cursors; KEYS, SMEMBERS and HGETALL order                 | from SipHash                                                             | from our hash: different values and order                                                                        |
| INCRBYFLOAT, HINCRBYFLOAT                                      | 80-bit long doubles                                                      | 64-bit doubles; last digits can differ                                                                           |
| Largest bulk string                                            | 512 MB                                                                   | 64 MB (V8's string limit)                                                                                        |
| Memory numbers                                                 | measured by the allocator                                                | estimates (section 10.5)                                                                                         |
| Snapshot file                                                  | RDB                                                                      | our own format (section 11.2)                                                                                    |
| AOF                                                            | multi-part directory, optional RDB preamble                              | one file of commands                                                                                             |
| BGSAVE                                                         | `fork()` and OS copy-on-write                                            | time slices and copy-on-write in code                                                                            |
| DEBUG DIGEST                                                   | Redis's algorithm                                                        | ours; compare MiniRedis with MiniRedis only                                                                      |
| Replication                                                    | with any Redis, chained replicas                                         | MiniRedis only, no chains                                                                                        |
| Auth                                                           | ACL users                                                                | one password                                                                                                     |
| INFO                                                           | dozens of fields                                                         | the fields in section 13.1                                                                                       |
| Multibulk count in a request                                   | up to INT_MAX (2,147,483,647)                                            | up to 1,048,576, then `invalid multibulk length` (spec 7.4: a client can't make us expect two billion arguments) |
| Bytes after a bulk in a request                                | the two bytes are skipped unchecked (`$4\r\nPINGxx` runs PING)           | must be `\r\n`, or `-ERR Protocol error: expected '\r\n' after bulk` and the connection closes (spec 10.1)       |
| A NUL byte in a request header line                            | `strchr` stops at it, so Redis waits for more data until the 64 KB limit | the line is parsed and rejected at once as an invalid length. Both reject the frame; only the timing differs     |
| Doubles that sit exactly halfway between two 17-digit decimals | Grisu2 (fpconv) picks one digit, e.g. `1234567890123456.7`               | JS's shortest round-trip digits pick the even one, `1234567890123456.8`. Both parse back to the same double      |
